1. `scripts/backup-db.sh`: очистка старых копий падала при пустом списке архивов файлов (`pipefail`). Исправлено, пустой список не считается ошибкой.
2. `test/backup.test.js`: контрольная сумма повреждённой копии называла исходный дамп. Исправлено в тесте: сумма называет свой файл.
3. `test/flags-operator.test.js`: ключ шифрования передаётся тесту явно, без переменных окружения в `package.json` (работает в PowerShell).
4. `src/store.js` и `src/store-memory.js`: журнал изменений флагов возвращает имена столбцов таблицы, как читает его команда из расшифровки. Раньше было camelCase — это моя ошибка при восстановлении.
5. `src/server.js`: ранняя проверка обслуживания блокировала выход и обновление сессии. Приведено к поздней проверке: эти два маршрута разрешены.
