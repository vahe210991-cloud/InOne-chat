# Справочный клиент организаций (Dart), шаг 5.9

**НЕ ПРОВЕРЕНО.** В среде разработки не было Dart SDK, поэтому этот код не компилировался и не запускался. Он написан по контракту `ORG_API.md` и разрешён владельцем проекта без проверки. Перед использованием обязательно выполните:

    dart pub get
    dart analyze
    dart test

Что есть: разбор ошибок сервера в ключи сообщений (`org_errors.dart`), модель организации (`org_models.dart`), HTTP-клиент для `GET /orgs/mine` и выхода из организации (`org_api.dart`), логика выбора организации без зависимостей от Flutter (`org_picker.dart`).

Чего нет: экрана выбора организации (виджет Flutter). Его делают в клиентском проекте, когда он определён. Тексты сообщений здесь на русском по умолчанию; локализация подключается по ключам `org.error.*`.
