# Проверка inone-engine-poc 0.6.0-alpha.9 (беседы, ключи, очередь и отправки в PostgreSQL)

Среда: контейнер, PostgreSQL 16, Node.js v22.22.2.

## Итоги

- Набор в памяти: 53 из 53.
- Набор на PostgreSQL: 27 из 27 (включая три новых теста перезапуска SD19–SD21).
- Поломки BR16–BR19 пойманы своими тестами. После каждой поломки эталонный файл восстанавливался и сравнивался побайтово.

## Что проверено

- Беседа, участники и история переживают перезапуск; вступивший позже не видит прошлого (SD19).
- Публичные ключи и одноразовые ключи переживают перезапуск; одноразовый ключ выдаётся один раз; счётчик сохраняется (SD20).
- Очередь доставки переживает перезапуск; подтверждённое не отдаётся снова; повтор отправки после перезапуска не дублирует сообщение (SD21).
- Прежние наборы проходят без изменения ожиданий: 53 из 53 в памяти, 24 из 24 старых тестов на PostgreSQL.

## Поломки: каждое правило заменялось ошибочным вариантом по одному

| Поломка | Тест, который её поймал |
|---|---|
| BR16: беседы не пишутся в базу | SD19 |
| BR17: очередь доставки не пишется в базу | SD21 |
| BR18: ключи устройства не пишутся в базу | SD20 |
| BR19: повтор отправки не распознаётся (проверка окна убрана) | SD21 |

## Найдено при проверке

- Первый прогон поломок выполнен при остановленной базе. Все три теста падали с `ECONNREFUSED`, поэтому тот прогон не учитывается. Прогоны повторены при работающей базе, и каждая поломка ловится только своим тестом.
- Тест SD20 сначала исходил из неверного предположения, что одноразовые ключи загружаются при создании аккаунта. Предположение исправлено: тест сам загружает ключи и публикует их.

## Не проверено и известные ограничения

- Событие с истёкшим сроком удаляется, только когда устройство его читает. Строки устройств, которые не синхронизируются, копятся. Нужна фоновая очистка.
- Работа под нагрузкой и с несколькими процессами сервера не проверялась; конкурентность опирается на блокировки строк в коде.
- Производительность не измерялась: синхронизация делает больше запросов к базе.
- SMS (D5) не подключён: восстановление держится на одном факторе, почте.
- Нестабильность теста C-04 (время ответа) не устранена.
