# Проверка inone-engine-poc 0.6.0-alpha.3 (устройства и токены в базе)

Среда: контейнер, PostgreSQL 16.15, Node.js v22.22.2.

## На реальной базе: 14 из 14

| Тест | Что проверяет |
|---|---|
| DB1–DB6 | хранилище: перебор PIN, дубликаты отправок, одноразовые ключи, очередь, токены и коды восстановления в виде хэшей |
| SD1–SD5 | аккаунты и PIN по HTTP: регистрация, гонка регистраций, перебор PIN по сети, блокировка через перезапуск |
| SD6 | токен входа переживает перезапуск сервера |
| SD7 | отозванное устройство остаётся отозванным после перезапуска; его токен отклоняется |
| SD8 | после перезапуска сервер помнит активные устройства: новый вход ждёт подтверждения (202) |

## Поломки: каждое правило заменялось ошибочным вариантом, по одному

| Поломка | Тест | Что показал тест |
|---|---|---|
| Сервер держит устройства и токены в своей памяти и игнорирует базу | SD5 | вход после перезапуска отклонён: 401, аккаунт пропал |
| | SD6 | ожидалось 200, получено 401: токен потерян |
| | SD7 | ожидалось 200, получено 401: устройство ноутбука потеряно |
| | SD8 | ожидалось 202, получено 401: аккаунт потерян |
| Отзыв устройства не сохраняется в базе | SD7 | ожидалось 401, получено 200: отозванный телефон принят после перезапуска |

После восстановления файлов: 14 из 14 на базе, 46 из 46 в памяти.

## Не проверено

- Подтверждение нового устройства (запросы подтверждения), блокировка входа по логину, очередь, беседы, ключи и восстановление пока работают в памяти.
- Несколько процессов сервера одновременно; нагрузка выше 40 параллельных запросов.
