| Поломка | Тест | Что показал тест |
|---|---|---|
| Токен выдаётся без условного обновления, с паузой | SD9 | ожидалось 1, получено 9 |
| Лимит входа читается без блокировки строки, с паузой | SD10 | ожидалось 5 отказов, получено 40 |
| Счётчик попыток кода без блокировки, с паузой | SD11 | ожидалось 3 отказа, получено 20 |
| Запросы подтверждения хранятся только в памяти сервера | SD12 | ожидалось 200, получено 401 на списке запросов: токен телефона потерян вместе с памятью сервера |

После восстановления файлов: 18 из 18 на базе, 46 из 46 в памяти.

## Не проверено

- Очередь, беседы, ключи и восстановление пока работают в памяти.
- Выдача токена и смена устройства не в одной транзакции (см. CHANGELOG).
- Несколько процессов сервера одновременно; нагрузка.
