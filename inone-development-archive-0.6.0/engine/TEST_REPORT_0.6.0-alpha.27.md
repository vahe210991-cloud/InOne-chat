- Тест с восемью аккаунтами падал на ограничении регистраций с одного адреса. Это защита сервера, а не ошибка. Для теста поднят лимит регистраций только на его собственном сервере.
- Во время проверки база один раз остановилась между вызовами; перед каждым прогоном теперь проверяется её доступность.
