# Отчёт о завершении этапа 4: сообщения групп через серверный контракт

- **Завершён:** 2026-11-01 10:10 UTC (Ереван UTC+4).
- **Этап:** сообщения групп MLS проходят через сервер: сервер проверяет группу и эпоху по открытому заголовку, шифротекст не читает.

## Цель этапа

Участник группы отправляет шифротекст MLS через сервер, остальные участники его получают и расшифровывают. Сервер отказывает сообщениям не той группы, не той эпохи и не от удалённых участников. Старый маршрут сообщений не обходит проверку для групп с эпохой. Правка не подменяет шифротекст в группах MLS.

## Что сделано

- **Маршрут `POST /mls/groups/:id/messages`.** Сообщение — шифротекст MLS в base64, до 64 КБ. Проверяются: участник группы, права `send_messages`, `send_stickers_gifs`, `forward_messages` для соответствующих видов, идентификатор группы в заголовке совпадает с комнатой, эпоха в заголовке совпадает с текущей эпохой группы (иначе 409 с текущей эпохой), группа уже имеет эпоху (иначе 409).
- **Разбор заголовка (`src/mls-wire.js`).** Читает версию, формат, идентификатор группы (переменная длина 1, 2, 4 или 8 байт) и эпоху (uint64). Обрезанные и чужие сообщения отклоняются.
- **Старый маршрут `POST /rooms/:id/events` закрыт** для групп с эпохой: отвечает 409 и указывает на новый маршрут.
- **Правка сообщений MLS отклоняется** (409): подмена шифротекста не проходит, пока нет отдельного контракта правки с проверкой эпохи.
- **Тесты:** `test/mls-messages.test.js`, 7 тестов в памяти и на PostgreSQL; `test/mls-wire.test.js`, 2 теста разбора заголовка.
- **Поломки:** проверка эпохи — падает тест; проверка группы — падает тест; закрытие старого маршрута — падает тест; запрет правки — падает тест. Файлы восстановлены побайтно.

## Проверки

- **Полный набор:** 253 из 253 в памяти; 253 из 253 на PostgreSQL; тесты базы и миграций 39 из 39.
- **Чистая копия:** архив без установленных пакетов, установка по файлу блокировки, полный набор на новой базе — те же результаты.
- **Сверка с кодом:** 7 из 7 заявленных свойств подтверждены по коду в чистой копии.
- **Замена агента с чистым контекстом:** проверку выполнял тот же исполнитель, что писал код, на чистой копии и по списку, составленному до проверки.

## Чего не сделано

- **Правка сообщений MLS.** Сейчас запрещена. Нужна правка с проверкой эпохи и группы, как у новых сообщений.
- **Группы без эпохи.** Пока в комнате нет ни одного коммита, старый маршрут событий открыт. Это сообщения без проверки MLS. Закрыть для всех групп — решение владельца.
- **Удаление сообщения MLS** отдельным тестом не проверено. Маршрут удаления не менялся.
- **Реакции и пересылка для MLS.** Поля принимаются, но их смысл для групп MLS не проверен.
- **Доставка оффлайн-устройствам** работает через существующую синхронизацию, она не менялась и не проверена на шифротексте MLS в сценарии с отключённым устройством.
- **Продуктового клиента нет.** Проверка сделана эталонным клиентом в тестах.

## Риски

- Группы без эпохи принимают сообщения по старому маршруту без проверки MLS. Перед запуском это надо закрыть.
- Проверка группы и эпохи — на стороне сервера по открытому заголовку. Расшифровка и подлинность отправителя — на клиентах.

## Следующий шаг

Решение владельца: закрыть старый маршрут сообщений для всех групп (без MLS сообщения не принимаются), или сначала правка сообщений MLS с проверкой эпохи.
