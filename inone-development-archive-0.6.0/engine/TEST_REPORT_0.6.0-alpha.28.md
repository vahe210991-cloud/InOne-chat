## Новые тесты

1. Менять оформление может тот, у кого есть право `edit_group_appearance`.
2. Описание до 500 символов; фон — только цвет `#RRGGBB` или сброс.
3. Аватар публичной группы — настоящее изображение; подделка и слишком большой файл отклоняются.
4. В приватной группе файлы только зашифрованные, в публичной — только открытые.
5. Публичная группа: файл виден постороннему; приватная: только участникам.
6. Смена видимости сбрасывает файлы и ссылки; аватар нельзя поставить обложкой.
7. Стикеры: добавляет тот, у кого есть право; имя уникально; число ограничено 50.
8. Удалённый файл не остаётся на сервере; журнал не хранит содержимое файлов.
