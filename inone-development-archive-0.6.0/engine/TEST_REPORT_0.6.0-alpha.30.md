- `test/config.test.js`, 8 тестов: продакшен без почты, с коротким перцем, открытой регистрацией, адресом без https; разработка; неверные числа.

- `test/migrate.test.js`, 3 теста, на PostgreSQL: новая база; старая база alpha.21 с данными; миграция, уже применённая вручную, не выполняется повторно.

## Проверка как процесс

1. `node src/migrate.js` на новой базе: схема создана, 30 таблиц, 5 миграций записаны. Повторный запуск: ничего не применено.
2. Запуск в продакшене без базы: код выхода 1, причина в сообщении.
3. Запуск в продакшене с полной настройкой: код выхода 1, причина «нужен реальный почтовый транспорт». Это ожидаемо: транспорта в сборке нет.
4. Запуск в разработке: `/healthz` 200, `/readyz` 200, неизвестный путь 404.
5. Остановка по `SIGTERM`: код выхода 0, в журнале `shutting down` и `stopped`.
6. Журнал запуска проверен поиском фиксированного текста: значение перца не найдено (0 совпадений).

Замечание о проверке: сначала поиск по переменной дал ложное совпадение, потому что переменная в основной оболочке была пуста (команда выполнялась в фоне). Повторная проверка с явным значением и поиском фиксированного текста дала 0.

## Правила, сломанные намеренно

| Правило | Упавший тест |
|---|---|
| Лимит тела запроса | слишком большое тело запроса отклоняется с 413 |
| Строка запроса в журнале | журнал не содержит строку запроса |
| Лимит журнала в памяти | журнал ограничен и не растёт без предела |
| Короткий перец в продакшене | короткий или тестовый перец отклоняется |
| Почтовый транспорт в продакшене | продакшен без реального почтового транспорта не стартует |
| Https в продакшене | продакшен требует адрес https |

Каждый раз падал один тест. После восстановления файлы совпадают с оригиналами побайтно.

- Docker-образ и `docker-compose.yml` не собраны.
- Продакшен-запуск невозможен: нет почтового транспорта.
- Нагрузка и длительная работа не проверялись.
