- **В памяти: 168 из 168.** 157 прежних тестов и 11 новых в `test/invites.test.js`.
- **На PostgreSQL: не запускалось.**
- **QR-код:** построен библиотекой `qrcode`, совпадает с ссылкой. Сканирование телефоном не проверялось.

## Новые тесты

1. Создать ссылку может только тот, у кого есть право приглашать; ответ содержит ссылку и QR-код.
2. Вступление по ссылке: участник входит сразу и читает только то, что написано после вступления.
3. Ссылка с заявкой: вступление создаёт заявку, одобрение добавляет; повторная заявка не создаёт дубликата.
4. Ссылка с лимитом вступлений: после исчерпания вступить нельзя.
5. Ссылка истекает через 7 дней по умолчанию.
6. Отозванная ссылка не работает; список ссылок не показывает токен.
7. Неверная ссылка и исчерпанная выглядят одинаково; участник второй раз по ссылке не вступает.
8. Приватная группа открывается только по ссылке.
9. Токен не хранится на сервере в явном виде и не попадает в журнал запросов.
10. QR-код строится из той же ссылки.
11. Неверные параметры ссылки отклоняются.
