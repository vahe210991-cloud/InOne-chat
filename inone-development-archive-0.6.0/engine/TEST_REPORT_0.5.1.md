Сначала C-08 падал на отсутствующем тестовом методе `stateSnapshot`. Я добавил только его чтение, без изменения поведения, и повторил прогон: тогда тесты упали по существу.

## Изменённый существующий тест

`test/groups.test.js`, «новый участник не читает историю до своего входа». Прежнее утверждение требовало, чтобы старое сообщение приходило с признаком ошибки расшифровки. Это закрепляло утечку шифротекста. Теперь тест требует, чтобы сервер не отдавал ни одного события до вступления.
