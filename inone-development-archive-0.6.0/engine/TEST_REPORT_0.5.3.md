# Проверка inone-engine-poc 0.5.3 (C-20)

Среда: контейнер, Node.js v22.22.2, npm 10.9.7. База данных не использовалась: тесты на памяти.

## Порядок проверки

1. Тесты `test/signals.test.js` написаны до исправления и запущены на 0.5.2. Все четыре падают:

| Тест | Что падало на 0.5.2 |
|---|---|
| C-20a | уведомление о входе с нового устройства не пришло (0 вместо 1) |
| C-20b | Bob не узнал о новом устройстве Alice |
| C-20c | Bob не узнал о новом участнике беседы |
| C-20d | поля `signals` нет в ответе: тест красный структурно, а не по поведению |

2. Контроль. Тот же код 0.5.2 без потери ответа доставляет изменение состава и изменение беседы (2 из 2). Значит, падения C-20b и C-20c вызваны потерянным ответом.

3. Исправление тестов. Первый вариант C-20b не создавал изменения состава: новое устройство не публиковало ключи. Тест исправлен до проверки красным, и результаты выше получены уже на исправленном тесте.

4. После исправления: новые тесты 4 из 4, полный набор 46 из 46 (35 старых, 7 доставки, 4 сигналов). Старые тесты не менялись.

5. Поломки: каждое правило по очереди ломалось в копии, соответствующий тест падал, файлы восстанавливались побайтово.

| Поломка | Упавший тест |
|---|---|
| Сигналы удаляются при чтении | C-20a, C-20b, C-20c |
| Повторные изменения не заменяют запись | C-20d |
| Клиент не подтверждает сигналы | C-20a |

6. После восстановления полный набор снова 46 из 46.

## Что не проверено

- Ни один тест не запускался на PostgreSQL.
- Мобильный клиент не менялся.
- Метаданные (C-19) не исправлены: тест на это не написан, потому что решение о модели контактов ещё не принято.
