Среда: контейнер, Node.js v22.22.2, PostgreSQL 16.15.

## Итоги

- **В памяти: 179 из 179.** Из них 10 в `test/appearance.test.js`.
- **На PostgreSQL: 179 из 179** (`DATABASE_URL=… npm test -- --test-concurrency=1`).
- **Тесты хранилища: 36 из 36** (`npm run test:db`).

## Что проверено

- Смена публичной группы в приватную не удаляет файлы: посторонний их не видит (404), участник получает 409 до замены.
- Замена тем же идентификатором: ссылки остаются, вид файла меняется по виду группы.
- Список ожидающих замены: видит тот, у кого есть право на оформление.
- Стикеры под другой вид группы не отдаются, пока их не заменили.
- Возврат в публичную группу: зашифрованный файл ждёт открытой загрузки.
- Аватар нельзя поставить обложкой; замена не меняет тип файла.
