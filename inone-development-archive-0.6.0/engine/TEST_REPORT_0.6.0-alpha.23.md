# Проверка inone-engine-poc 0.6.0-alpha.23 (редактирование и удаление сообщений)

Среда: контейнер, Node.js v22.22.2. PostgreSQL в этой среде не запускался.

## Итоги

- **В памяти: 141 из 141.** 133 прежних теста и 8 новых в `test/room-edit-delete.test.js`.
- **На PostgreSQL: не запускалось.**

## Новые тесты

1. Автор редактирует своё сообщение; чужое редактировать нельзя.
2. Без права `edit_own_messages` автор не редактирует.
3. Автор удаляет своё сообщение; содержимое исчезает из состояния сервера и из ответа.
4. Чужое удалить можно только с правом `delete_any_messages`; владелец имеет его всегда.
5. Удалённое сообщение нельзя удалить или отредактировать повторно.
6. Удаление убирает и правки сообщения из состояния сервера.
7. Посторонний не редактирует и не удаляет; неверный идентификатор и несуществующее сообщение отклоняются.
8. Журнал запросов сервера не хранит тела сообщений.

## Найдено и исправлено

Журнал запросов (`wireLog`) писал тела запросов, включая шифротекст сообщений. Удалённое сообщение оставалось в журнале. Исправлено: для комнат, правок и личных сообщений пишется пометка вместо тела. Тест 8 закрепляет это правило.

## Правила, сломанные намеренно

| Правило | Упавших тестов из 8 |
|---|---|
| Правка только автором | 1 |
| Удаление чужого требует `delete_any_messages` | 1 |
| Журнал не хранит тела сообщений | 1 |

После восстановления файл совпадает с резервной копией побайтно, 8 из 8.
