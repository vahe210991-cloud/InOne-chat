# Проверка inone-engine-poc 0.6.0-alpha.12 (подтверждение ссылки восстановления кнопкой)

Среда: контейнер, PostgreSQL 16, Node.js v22.22.2.

## Итоги

- Набор в памяти: 65 из 65.
- Набор на PostgreSQL: 29 из 29.
- Поломки BR29 и BR30 пойманы тестами. После каждой поломки файл сервера восстанавливался и сравнивался побайтово.

## Что проверено

- Открытие ссылки показывает страницу с формой POST и не меняет состояние: восстановление без кнопки после открытия ссылки не проходит (P8).
- Форма из браузера подтверждает ссылку; неверная ссылка возвращает страницу с ошибкой и код 403 (P9).
- JSON-запрос приложения подтверждает ссылку, как и раньше; неверная ссылка по POST отклоняется с 403 (P3).
- Прежние тесты восстановления, лимитов и телефона проходят без изменения ожиданий.

## Поломки

| Поломка | Тест, который её поймал |
|---|---|
| BR29: открытие ссылки подтверждает восстановление (GET меняет состояние) | P8: `открытие ссылки из письма не подтверждает…` |
| BR30: POST принимает любую ссылку | P3: `без подтверждения по ссылке…`; P9: `кнопка на странице…` |

## Найдено при проверке

- Прежняя версия подтверждала ссылку обычным GET. Предпросмотр почты мог бы подтвердить восстановление. Исправлено: подтверждение только POST, как у остальных действий, которые меняют состояние.

## Не проверено и известные ограничения

- Страница подтверждения минимальная: без стилей, текст только на русском.
- Реальная доставка писем и поведение почтовых клиентов не проверялись.
- Очистка истёкших событий и счётчиков не сделана (C-15).
- SMS-поставщик не подключён.
- Нестабильность теста C-04 не разобрана.
