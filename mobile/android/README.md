# Android native project

Canonical Android application ID: `com.inone.app`.

The complete Flutter/Gradle project is generated by `../tool/generate_flutter_platforms.sh android` using the pinned Flutter toolchain. The CI workflow generates this project before Android analysis, APK build, and emulator smoke tests.

The generator validates the repository-root `google-services.json` against Firebase project `inone-messenger`, sender ID `687951175916`, Android App ID `1:687951175916:android:7bb45a64913dd7797c05c9`, and package `com.inone.app`. It then installs the file at `android/app/google-services.json`.

Do not register a different package name in Firebase. See [platform identifiers](../PLATFORM-IDENTIFIERS.md). The Google Services Gradle plugin and Flutter Firebase runtime SDK must also be configured before Firebase can be initialized; copying the client file alone does not activate Firebase.
