# iOS native project

Canonical iOS Bundle ID: `com.inone.app`.

The complete Xcode project is generated by `../tool/generate_flutter_platforms.sh ios` using the pinned Flutter toolchain. The CI workflow generates this project before iOS simulator and device builds.

The generator validates the repository-root `GoogleService-Info.plist` against Firebase project `inone-messenger`, sender ID `687951175916`, iOS App ID `1:687951175916:ios:51b46acf985759337c05c9`, and bundle ID `com.inone.app`. It then installs the file at `ios/Runner/GoogleService-Info.plist`.

The native generator also creates Runner.entitlements, wires CODE_SIGN_ENTITLEMENTS, selects aps-environment=development for Debug/Profile and production for Release, and enables the remote-notification background mode. The app registers its Firebase Messaging background handler before runApp.

For delivery, upload the APNs authentication key (.p8) to Firebase Console for project inone-messenger with the matching Key ID and Apple Team ID. Keep the .p8, signing certificate and provisioning profile outside Git. The generated project configuration does not prove APNs delivery: a correctly signed physical iPhone and a real FCM send are still required.

Do not register a different Bundle ID in Firebase. See [platform identifiers](../PLATFORM-IDENTIFIERS.md).
