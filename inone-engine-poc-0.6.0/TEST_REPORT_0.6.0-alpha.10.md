# Проверка inone-engine-poc 0.6.0-alpha.10 (телефон аккаунта и восстановление по двум каналам)

Среда: контейнер, PostgreSQL 16, Node.js v22.22.2.

## Итоги

- Набор в памяти: 60 из 60.
- Набор на PostgreSQL: 28 из 28 (включая SD22 про подтверждённый номер).
- Поломки BR20–BR28 пойманы тестами. BR28 ловится только при поломке обоих уровней защиты (см. ниже). После каждой поломки файлы восстанавливались и сравнивались побайтово.

## Что проверено

- Регистрация без телефона отклоняется, если телефон обязателен; неверный формат номера отклоняется.
- Номер подтверждается кодом из SMS; неверный код не подтверждает.
- Номер, уже подтверждённый другим аккаунтом, не принимается (в памяти и на базе).
- Код подтверждения телефона: не чаще трёх SMS в час на аккаунт.
- Смена номера требует пароль; без пароля или с чужим паролем номер не меняется.
- Восстановление: код из SMS и переход по ссылке из письма. Без любого из них не проходит. Чужая ссылка не подтверждает.
- Для аккаунта без подтверждённого телефона восстановление ничего не отправляет.
- Пять неверных кодов блокируют запросы на час; не больше трёх запросов в час (прежние тесты, теперь на SMS-коде).
- В снимке состояния сервера нет ни кода из SMS, ни ссылки (C-08).

## Поломки

| Поломка | Тест, который её поймал |
|---|---|
| BR20: ссылка не требуется перед кодом | `без подтверждения по ссылке…` |
| BR21: код из SMS не проверяется | `восстановление: новый пароль сразу…`, `после пяти неверных кодов…` |
| BR22: восстановление без подтверждённого телефона | `восстановление для аккаунта без подтверждённого телефона…` |
| BR23: телефон не обязателен при регистрации | `регистрация без телефона отклоняется…` |
| BR24: один номер у двух аккаунтов (в памяти) | `один подтверждённый телефон не может принадлежать двум аккаунтам` |
| BR25: нет ограничения на SMS с кодом | `код подтверждения телефона приходит не чаще трёх раз в час` |
| BR26: любая ссылка принимается | `без подтверждения по ссылке…` |
| BR27: смена номера без пароля | `смена номера требует пароль…` |
| BR28: на базе не видно подтверждённый номер другого аккаунта | не поймана (см. ниже) |
| BR28b: сломаны оба уровня (запрос на базе и уникальный индекс) | `SD22` |

## Найдено при проверке

- Смена номера без пароля позволяла украденному устройству сменить номер на свой и затем восстановить доступ по SMS. Исправлено: смена номера требует пароль, тест добавлен.
- BR28 не поймана: при поломке только запроса владельца номера уникальный индекс в базе отклоняет второй номер тем же ответом 409. Это защита в две линии, и тест ловит только одновременную поломку обеих (BR28b).

## Не проверено и известные ограничения

- Реальная доставка SMS и писем. Поставщик SMS не подключён: адаптер и тестовый провайдер.
- Регистрация не ограничена по адресу: возможна накрутка аккаунтов и SMS.
- Переход по ссылке — одним GET; почтовый сканер может открыть ссылку заранее. Без SMS-кода восстановления не будет, но подтверждение лучше сделать кнопкой (POST).
- Нестабильность теста C-04 не устранена.
- Очистка истёкших событий очереди и счётчиков входа не сделана.
