## Новые тесты

1. Приватная группа не находится поиском, и посторонний не может в неё вступить (404).
2. Публичная группа находится по названию; состав видят только участники.
3. Вступление по умолчанию по заявке: заявку видит тот, у кого есть право приглашать.
4. Свободный вход: участник входит сразу и читает только то, что написано после вступления.
5. Одобрить заявку может только тот, у кого есть право приглашать.
6. Повторная заявка не создаёт дубликата; переход в приватную группу отменяет заявки.
7. Участник, вступивший по заявке, получает права по умолчанию.
8. Поиск: короткий запрос отклоняется, символы подстановки ничего не открывают.
