# Проверка inone-engine-poc 0.6.0-alpha.1 (хранилище PostgreSQL)

Среда: контейнер, PostgreSQL 16.15 (Ubuntu), Node.js v22.22.2. Сервер работает в памяти; проверяется хранилище на реальной базе.

## Что проверяется на реальной базе

| Тест | Правило | Что проверяет |
|---|---|---|
| DB1 | перебор PIN | 40 параллельных неверных PIN дают ровно 5 реальных проверок; верный PIN во время блокировки не проверяется |
| DB2 | дубликаты отправок (C-05) | 20 параллельных повторов одной отправки дают одну запись без ошибок |
| DB3 | одноразовые ключи | 20 параллельных выдач пяти ключей отдают каждый ключ не больше одного раза (хорошая практика из реестра, сохранена) |
| DB4 | очередь (C-05, C-20) | подтверждение одного потока не трогает другой; повтор заменяет запись; истёкшее не отдаётся |
| DB5 | токены (C-08) | в таблицах нет открытого токена; вход по токену работает |
| DB6 | коды восстановления (C-08) | в таблице только ключевой хэш; верный код проходит, неверный нет |

## Поломки: каждое правило заменялось наивным вариантом, по одному

| Наивный вариант | Тест | Что показал тест |
|---|---|---|
| Чтение PIN без блокировки, с паузой внутри | DB1 | `40 !== 5`: все 40 попыток дошли до проверки |
| Проверка и вставка без защиты уникальным ключом, с паузой | DB2 | 13 ошибок уникального ключа вместо одной записи |
| Выдача одноразового ключа без блокировки, с паузой | DB3 | `20 !== 5`: все 20 запросов получили ключ |
| Сигналы подтверждаются номером событий доставки | DB4 | не совпал список потоков: сигнал, который не подтверждён, удалён |
| Токен хранится открытым текстом | DB5 | открытый токен найден в таблице |
| Код восстановления хранится открытым текстом | DB6 | код найден в таблице |

После восстановления файла: 6 из 6. Полный набор в памяти: 46 из 46.

## Что не проверено

- Сервер не переведён на хранилище: HTTP-маршруты с базой в тестах не работают.
- Параллельность проверена одним процессом. Блокировки строк действуют на уровне базы, но между несколькими процессами сервера это не проверено.
- Нагрузка выше 40 параллельных запросов.
- Миграции схемы и очистка по сроку.
