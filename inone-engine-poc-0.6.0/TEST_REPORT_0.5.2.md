# Проверка inone-engine-poc 0.5.2 (C-05)

Среда: контейнер, Node.js v22.22.2, npm 10.9.7. База данных не использовалась: тесты на памяти.

## Порядок проверки

1. Тесты `test/delivery.test.js` написаны до исправления и запущены на 0.5.1. Все семь падают по существу:

| Тест | Что падало на 0.5.1 |
|---|---|
| C-05a | повторный запрос без подтверждения вернул 0 событий вместо 1 |
| C-05b | событие старше 30 дней всё ещё отдавалось |
| C-05c | в очереди оказались две копии одной отправки |
| C-05d | после потерянного ответа ключ беседы не расшифровался |
| C-05e | повторная партия обработана второй раз |
| C-05f | синхронизация упала на одном непонятном событии |
| C-05g | `since=abc` принято, ответ 200 вместо 400 |

2. После исправления: новые тесты 7 из 7; полный набор 42 из 42 (35 старых и 7 новых). Старые тесты не менялись.

3. Поломки: каждое правило по очереди ломалось в копии, соответствующий тест падал, файл восстанавливался побайтово.

| Поломка | Упавший тест |
|---|---|
| Сервер удаляет события без подтверждения (`since` не учитывается) | C-05a |
| Срок хранения 30 дней не проверяется | C-05b |
| Повтор отправки создаёт вторую копию | C-05c |
| Клиент обрабатывает повторно пришедшее событие | C-05e |
| Ошибка одного события останавливает синхронизацию | C-05f |
| Клиент никогда не подтверждает события | C-05e |

4. После восстановления полный набор снова 42 из 42.

## Что не проверено

- Ни один тест не запускался на PostgreSQL. Порт на базу ещё впереди.
- Мобильный клиент не менялся. Правило «подтверждать после записи в базу» проверяется на нём, в PoC у клиента нет слоя хранения.
- Тесты на время и срок (30 дней) используют сдвиг часов сервера, а не реальное время.
