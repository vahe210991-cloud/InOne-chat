# Аккаунт владельца в базе сервера

- **Обновлено:** 2026-11-01 10:08 UTC

## Что это

Первичный аккаунт владельца создаётся в вашей базе командой, которую вы запускаете один раз на своём сервере. Письмо для этого не нужно: вы подтверждаете оператором, что почта ваша. Это решение записывается в журнал. Дальше вход — обычный, по паролю.

Я не могу записать аккаунт в вашу базу отсюда: у меня нет доступа к ней, а база будет на вашем локальном сервере.

## Что нужно заранее

1. PostgreSQL запущен, база создана (например `inone`), пользователь с правами на неё.
2. Миграции применены: `DATABASE_URL=... npm run migrate`.
3. Перец: `INONE_PIN_PEPPER` — 32 символа и больше, случайные. Его надо сохранить: без него база не работает.
4. Пароль: 8 символов и больше.
5. Никнейм: от 3 до 20 символов, латиница, цифры, точка и подчёркивание, начинается с буквы.
6. Телефон (необязательно): в формате `+код страны`, номер из разрешённых стран (по умолчанию страны СНГ, Европа, США, Канада).

## Команда

Пароль лучше задать так, чтобы он не попал в историю команд:

```
read -s INONE_OWNER_PASSWORD && export INONE_OWNER_PASSWORD
DATABASE_URL='postgresql://inone:<пароль базы>@localhost:5432/inone' \
INONE_PIN_PEPPER='<перец, 32 символа и больше>' \
node scripts/bootstrap-owner-account.mjs ваша@почта.example ваш_никнейм +374XXXXXXXX --i-confirm-email-is-mine
unset INONE_OWNER_PASSWORD
```

Команда выводит «аккаунт создан» и идентификатор. Пароль не выводится. Второй запуск с той же почтой или никнеймом откажет.

## Вход

Когда сервер запущен (`npm start`), вход по паролю работает запросом к `/login`. Клиента (приложения с экранами) ещё нет: вход через приложение будет, когда оно появится.

## Что не сделано

- **Почта.** Письма с кодом пока не отправляются: нет домена и почтового ящика. Почта, которую вы указали, отмечена как подтверждённая оператором. Восстановление доступа по почте заработает после настройки почты.
- **Кодовое слово и имя с фамилией.** Это требования, которые вы утвердили, но их пока нет в коде. Аккаунт, созданный сейчас, их не получит. Добавим, когда будем делать регистрацию для клиента.
- **Телефон.** Если указан, номер закрепляется за аккаунтом в ожидании подтверждения по SMS. SMS пока не подключены.

## Проверка

Тесты процедуры: 5 тестов в памяти и на PostgreSQL. Поломка: создание без подтверждения оператора — падает тест. Файлы: `src/bootstrap-owner.js`, `src/account-rules.js`, `scripts/bootstrap-owner-account.mjs`, `test/bootstrap-owner.test.js`.
