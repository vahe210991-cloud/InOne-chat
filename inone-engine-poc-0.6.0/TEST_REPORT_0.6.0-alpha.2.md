# Проверка inone-engine-poc 0.6.0-alpha.2 (аккаунты и PIN в базе)

Среда: контейнер, PostgreSQL 16.15, Node.js v22.22.2.

## На реальной базе: 11 из 11

| Тест | Что проверяет |
|---|---|
| SD1 | регистрация, повтор отвечает 409, вход по верному паролю даёт токен, неверный пароль 401 |
| SD2 | 20 параллельных регистраций одного логина: одна 200, остальные 409, ошибок нет |
| SD3 | PIN задаётся, неверный PIN не снимает защиту, верный снимает, после снятия ответ 404 |
| SD4 | 40 параллельных неверных PIN по HTTP: ровно 5 реальных проверок, 5 ответов 403, 35 ответов 429 |
| SD5 | блокировка PIN переживает перезапуск сервера; после перезапуска проверок не было |
| DB1–DB6 | хранилище, как в 0.6.0-alpha.1 |

## Поломки: каждое правило заменялось наивным вариантом, по одному

| Наивный вариант | Тест | Что показал тест |
|---|---|---|
| Сервер игнорирует переданное хранилище и держит всё в памяти | SD5 | после перезапуска вход отклонён (401): аккаунт пропал |
| Чтение PIN без блокировки строки, с паузой | SD4, DB1 | `40 !== 5`: все 40 попыток дошли до проверки |
| Регистрация без защиты уникальным ключом | SD1, SD2 | `500 !== 409`: повторная регистрация даёт ошибку сервера |

После восстановления файлов: 11 из 11 на базе, 46 из 46 в памяти.

## Не проверено

- Устройства, токены, очередь, беседы, ключи и восстановление пока работают в памяти.
- Несколько процессов сервера одновременно.
- Нагрузка выше 40 параллельных запросов.
