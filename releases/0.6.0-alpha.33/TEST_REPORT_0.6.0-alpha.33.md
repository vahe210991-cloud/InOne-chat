- Изоляция (6 тестов): поломка проверки членства в четырёх обработчиках (события, эпоха, состав, ссылка на файл). Каждая ловится проверкой постороннего. Сервер возвращён побайтно.
- Защита входа и ввода (4 теста): неверный JSON с деталями, заголовки снятые с ответов, маршрут записи конфигурации по сети, поле хеша PIN в профиле. Каждая ловится. Сервер возвращён побайтно.
- Журнал: `DELIBERATE_BREAKS.md`.

## Покрытие правил защиты входа и ввода
| Правило | Где проверяется |
|---|---|
| Блокировка входа после неверных паролей | `bruteforce`, `delayed-login` |
| Блокировка PIN с ростом задержки; параллельный перебор | `security` |
| Одинаковые ответы на неизвестный логин и выравнивание времени | `bruteforce`, `hardening` |
| Лимит размера тела запроса (413) | `server-ops` |
| Защитные заголовки ответов (включая ошибки) | `server-ops`, `security-matrix` |
| Неверный JSON без деталей разбора | `security-matrix` |
| Запись конфигурации по сети закрыта | `security-matrix`, `remote-config` |
| Секреты и хеши не попадают в ответы | `security-matrix` |
| Код телефона не чаще трёх раз в час | `recovery` |
| Блокировка кода действия после пяти неверных попыток | `stepup` |
| Попытки кода отмены восстановления ограничены | `recovery-email` |
| Попытки кода одобрения нового устройства ограничены (3) | `server-db` (PostgreSQL) |
| Восстановление аккаунта: 48 часов ожидания, коды хранятся как хеши | `delayed-login`, `hardening`, `recovery` |

## Ограничения
- Проверка «чистым контекстом» (отдельный проверяющий агент) не выполнена: в этой среде такого агента нет.
- Внешнего аудита и внешнего теста на проникновение нет.
- Изоляция не покрывает пока: приглашения в ожидании одобрения, посылки MLS, вложения приватных групп, ключевые пакеты чужих пользователей, утечки поиска пользователей.
- Отправка SMS и уведомлений FCM/APNs не подключена: нужны ваши аккаунты и адаптер (решение владельца).
- Файлы копий, ключ шифрования копий и место внешней копии не выбраны (решение владельца).
