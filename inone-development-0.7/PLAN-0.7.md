## 3. Раздел 0.7 — экраны (вес 30%)

Общие правила:
- одна ветка на экран: `screen/0.7.N-<имя>`;
- код в папке `client-screens/<имя>/`, тесты логики, сквозной сценарий против движка, отчёт, архив этапа;
- вид страницы проверяет владелец в браузере;
- токен входа хранится только в памяти вкладки, без localStorage и cookies.

Риски:
- Шифрование в браузере: без клиентского MLS экраны чата и групп не работают. Главный риск, решается в 0.7.0a.
- Визуальную проверку выполняет только владелец.
- Группы с 500 и более участниками: списки листаются постранично.
- Биометрия общая с Propo: изменения согласуются через репозиторий Propo.
- Доступа к GitHub из этого чата нет: поставка через bundle и архивы.
