# Проверки поломками (deliberate breaks)

В каждом случае в рабочей копии временно ломали одну проверку, запускали тест, который её обязан ловить, и возвращали файл. После возврата содержимое файла проверено побайтно (SHA-256 совпал).

| Поломка | Файл | Тест | Упало | Прошло | Итог |
|---|---|---|---|---|---|
| Сессии: повтор старого токена обновления не распознаётся | см. таблицу в scripts | `test/sessions.test.js` | 1 | 4 | поймано |
| Файлы: подпись ссылки загрузки не проверяется | см. таблицу в scripts | `test/files.test.js` | 1 | 8 | поймано |
| Уведомления: отправивший получает уведомление о своём сообщении | см. таблицу в scripts | `test/push.test.js` | 2 | 2 | поймано |
| Конфигурация: режим обслуживания не блокирует записи | см. таблицу в scripts | `test/remote-config.test.js` | 1 | 4 | поймано |
| Резервная копия: повреждённая копия восстанавливается без проверки суммы | см. таблицу в scripts | `test/backup.test.js` | 1 | 1 | поймано |

Тест, который упал, — первый из перечисленных в выводе запуска. Поломки сделаны в исходном коде движка и скрипте копирования; тесты и файлы после возврата совпадают с версией до поломки.

## Этап: изоляция данных участников (пункт 2)

Поломка: в обработчике снимается только проверка членства, остальное не меняется. Тест — `test/isolation.test.js`.

| Поломка | Строка | Что упало |
|---|---|---|
| События комнаты читаются без проверки участника | 2113 | посторонний получает 200 вместо отказа |
| Эпоха группы читается без проверки участника | 1876 | посторонний получает 200 вместо отказа |
| Состав комнаты читается без проверки участника | 1502 | посторонний получает 200 вместо отказа |
| Ссылка на файл комнаты выдаётся без проверки участника | 1079 | посторонний получает 409 (файл не готов) вместо отказа по доступу |

Ошибка в первом прогоне поломок: подмена оставляла `r.` перед условием и делала отказ всем, включая участников. Поэтому тесты ловили поломку через контрольные случаи участника, а не через проверку постороннего. Прогон исправлен: снимается только условие членства; после этого каждая поломка ловится проверкой постороннего.

| Посторонний загружает файл в комнату (оба слоя: членство и возможность) | тест «файлы: посторонняя организация не загружает файл…» (файл принят) |

Замечание о двух слоях. Загрузка файла и приглашения защищены сразу двумя проверками: членством и возможностью. Поломка одного слоя не видна тесту, потому что второй слой отсекает посторонних. Тест ловит поломку только тогда, когда оба слоя сняты. Это защита в глубину, а не пробел.

Пропущено: поиск по нику и выдача ключевых пакетов чужим пользователям. Причина: организация по умолчанию включает всех зарегистрированных пользователей (шаг 5.1), поэтому правило «общение между организациями закрыто» для них не действует. Нужно решение владельца о членстве по умолчанию; тесты будут включены после него.
