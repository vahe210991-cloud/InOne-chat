# Экраны раздела 0.7

Этап 0.7.0 — общий слой запросов к движку. Экраны этапов 0.7.1–0.7.11 добавляются отдельными папками.

Правила:
- токен входа хранится только в памяти вкладки: без localStorage, sessionStorage, IndexedDB и cookies;
- все тексты ошибок берутся из общего каталога (common/api.mjs), по полю code;
- состояния экрана (загрузка, пусто, готово, ошибка) — из common/state.mjs;
- экраны работают только через общий слой, без прямых вызовов fetch.
