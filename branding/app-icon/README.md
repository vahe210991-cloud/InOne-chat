# InOne app icon

This directory contains the editable vector master for the approved InOne app-icon direction.

## Master asset

- `inone-app-icon.svg`: 1024 × 1024 full-bleed square vector.
- Straight outer edges, no rounded-corner mask or external border.
- Lime-green background and dark raised `InOne` wordmark.
- The wordmark remains SVG text so it can be edited in Figma, Illustrator, or Inkscape. Rendering depends on the fonts available in the editor.

## Platform packaging

This SVG is the editable brand master, not yet the final native launcher bundle. Android adaptive icons and iOS app icons require platform-specific raster exports and configuration. Those generated PNG assets should be derived from this master and added in a separate mobile integration change after visual export review.
