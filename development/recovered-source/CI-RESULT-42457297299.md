## Sole PostgreSQL failure

Test: `test/backup.test.js`, “копия восстанавливается в пустую базу без потерь; повреждённая копия отвергается”.

The runner's `pg_dump/pg_restore` client was newer than the PostgreSQL 16 service. The dump contained:

`SET transaction_timeout = 0;`

PostgreSQL 16 rejected this with:

`ERROR: unrecognized configuration parameter "transaction_timeout"`

The other 42 database tests passed. This is a PostgreSQL client/server major-version mismatch in CI, not a P0 feature assertion failure.

## Correction committed

Workflow commit `0e13b9726c5fcbecfdb8a9a45b05d4bb6eb02863`:
- pins runner to `ubuntu-24.04`;
- installs `postgresql-client-16`;
- prepends `/usr/lib/postgresql/16/bin` to PATH;
- prints `pg_dump` and `pg_restore` versions for evidence.
