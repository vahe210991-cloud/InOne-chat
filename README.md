# InOne-chat

Secure messenger.

## Mandatory AI agent entry point

Every AI model/chat/developer must first read [`AGENTS.md`](AGENTS.md) and the complete [`development/AI-AGENT-MANDATE.md`](development/AI-AGENT-MANDATE.md). These instructions are mandatory for every session. GitHub reports and committed files—not chat memory—are the durable project record.

## Development workspace

Every developer/AI session must first read [`development/README.md`](development/README.md) and follow [`development/WORKING-RULES.md`](development/WORKING-RULES.md). The complete-repository copy/work/return protocol is mandatory. GitHub is the only durable source of truth; do not rely on model memory or local-only files.

## Project continuity

Before starting or resuming work, read [`docs/continuity/README.md`](docs/continuity/README.md). It is the persistent handoff index for all development sessions and contains the current state, approved decisions, source-artifact map, and exact next steps.

Do not rely on previous chat memory as the source of truth. Update `docs/continuity/` at the end of every substantial session.
