# Recovered Library artifacts

This directory preserves readable text artifacts from the InOne Library so they are accessible alongside the GitHub recovery work.

**Important:** these are source references and patch files, not an imported or tested P0 codebase. Do not apply the patches to the archived 0.6.0 tree; see [PATCH-COMPATIBILITY-REPORT.md](PATCH-COMPATIBILITY-REPORT.md).

The binary Git bundles, ZIP archives, and curated HTML design system remain blocked by the Project Files raw-byte access policy. The original Library files remain the source of truth.
